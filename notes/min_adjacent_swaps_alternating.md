# Fewest adjacent swaps to alternate a binary array

Only two alternating target patterns exist. For each pattern with the same number of ones, match the original one positions to target one positions in order. The total movement equals the number of adjacent swaps; crossing matches cannot improve it.

Complexity: O(n) time, O(n) space.
